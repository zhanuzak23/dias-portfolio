# Портфолио — Диас Жанұзақ

**Сайт:** https://zhanuzak23.github.io/dias-portfolio/

Статический сайт: HTML + CSS + JS. Без сборки, без `npm install`, без зависимостей.
Всё содержимое лежит в **одном файле** — `assets/js/content.js`.

Сайт обновляется автоматически: любой `git push` в ветку `main` пересобирает
GitHub Pages за минуту-две.

GitHub Pages кэширует `css` и `js` на 10 минут, поэтому свежие правки могут
не появиться сразу. Чтобы увидеть их немедленно, увеличь номер версии `?v=2`
у скриптов и стилей в `index.html` и `case.html` — или просто подожди.

---

## Как посмотреть локально

Просто открыть `index.html` двойным кликом **не получится** — браузер заблокирует
загрузку скриптов с `file://`. Нужен локальный сервер. В проекте лежит свой,
без зависимостей:

```bash
node serve.js
```

Дальше открыть `http://localhost:5173`. Поправил `content.js` → просто обнови страницу.

Альтернативы, если удобнее: `npx --yes serve .` или `python -m http.server 5173`.

## Порядок блоков на главной

1. **Hero** — фото, одна мета-строка, заголовок, одно предложение, чипы
2. **Кейсы** — 5 карточек, каждая ведёт на свою страницу
3. **Скиллы** — навыки в 3 колонки, инструменты, опыт, образование
4. **Контакты** — CV, LinkedIn, Telegram, почта, телефон
5. **Подвал**

Сверху — липкий меню-бар: имя, навигация, иконки заполненных контактов и кнопка
«Связаться». Пустые контакты в баре не показываются, чтобы не мусорить.

## Как наполнять

### 1. Правило пустой строки

Пустая строка `""` = на сайте появится заглушка:

- нет картинки → «Место для фото» с нужным размером
- нет контакта → кнопка гаснет и подписывается «скоро»

Как только вписываешь значение — заглушка пропадает сама. Ничего удалять не нужно.

### 2. Контакты

```js
contacts: {
  phone:    "+7 708 175 39 74",
  email:    "",                        // ← вписать
  telegram: "https://t.me/username",   // ← вписать
  linkedin: "",                        // ← вписать, когда будет
  cv:       "assets/files/cv.pdf",     // ← положить файл и вписать путь
}
```

Телефон и почта копируются в буфер по клику. Остальное — обычные ссылки.

### 3. Фото

1. Положить файл в `assets/img/cases/case-1/`
2. Вписать путь **от корня проекта**:

```js
cover: "assets/img/cases/case-1/cover.jpg",
```

Рекомендуемые размеры (они же подписаны на заглушках):

| Что | Размер | Пропорции |
|---|---|---|
| Фото в hero | 900×1200 | 3:4 |
| Обложка кейса в списке | 1600×1066 | 3:2 |
| Обложка на странице кейса | 1920×1080 | 16:9 |
| Картинка внутри кейса | 1600×1000 | 16:10 |
| Картинка в галерее (2 колонки) | 1200×900 | 4:3 |
| Картинка в галерее (3 колонки) | 900×1200 | 3:4 |
| OG-картинка для соцсетей | 1200×630 | — |

Формат — `.jpg` или `.webp`. Держи вес до ~300 КБ на картинку.

### 4. Страница кейса

Страница собирается из массива `blocks`. Доступные типы:

```js
{ type: "text",    title: "Задача",  body: ["абзац 1", "абзац 2"] }
{ type: "list",    title: "Что сделал", items: ["пункт", "пункт"] }
{ type: "image",   src: "...", hint: "1600×1000", caption: "подпись" }
{ type: "gallery", title: "Экраны", columns: 2, images: [{src, hint, caption}] }
{ type: "quote",   body: "цитата", author: "Имя, должность" }
{ type: "stats",   items: [{value: "+30%", label: "конверсия"}] }
```

Блоки можно **переставлять, дублировать и удалять** — страница соберётся по порядку.
Кейс 1 (Finalytics) собран на настоящем содержании — смотри его как пример.
Кейсы 2–5 — заготовки с рыбой.

Картинки в блоках `image` показываются целиком, без кадрирования: подойдут
скриншоты любых пропорций. Обрезается только обложка в списке кейсов — она
кадрируется от верхнего края, чтобы была видна шапка экрана.

Любая картинка на странице кейса открывается на весь экран по клику: стрелки
или ← → листают, клик по картинке показывает её в реальном размере, Esc
закрывает. Ничего настраивать не нужно — работает для всех блоков `image`.

### 5. Черновики

Текст-рыба помечен `draft: true`. В подвале сайта есть кнопка
**«показать черновики»** — она подсвечивает всё, что ещё не заменено на настоящий текст.
Заменил текст → поставь `draft: false` (или удали строку).

### 6. Добавить шестой кейс

Скопировать любой объект из массива `cases`, поменять `id` (например `"case-6"`) —
карточка и страница появятся сами.

## Как поменять визуал

Все цвета, отступы, радиусы и шрифты — переменные в начале `assets/css/style.css`:

```css
--bg:#0A0A0A;        /* фон */
--accent:#D6F94C;    /* акцент (лаймовый) */
--container:1240px;  /* ширина контента */
--gutter:40px;       /* боковые отступы */
```

Шрифт — Manrope, подключается из Google Fonts в `<head>` обоих HTML-файлов.

## Деплой на Vercel

Сборка не нужна — это статика.

**Вариант 1, через сайт:** vercel.com → Add New → Project → перетащить папку.
Framework Preset: **Other**, Build Command: пусто, Output Directory: пусто.

**Вариант 2, через терминал:**

```bash
npx vercel --prod
```

**Вариант 3, через GitHub:** залить папку в репозиторий и подключить его в Vercel —
дальше каждый `git push` будет обновлять сайт автоматически.
